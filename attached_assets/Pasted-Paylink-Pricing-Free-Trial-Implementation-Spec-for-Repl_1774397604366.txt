Part 3 — Trial and Billing Logic
Business rules
Trial rules
every company gets one free trial
trial lasts 30 days
trial can be canceled before billing begins
if trial expires and billing is not activated, account becomes restricted
Account state types

Use these statuses:

trial_active
trial_expired
active_paid
past_due
suspended
canceled
Recommended backend fields

Tell Replit to create these fields in the company or subscription table:

{
  "plan_name": "starter",
  "base_monthly_price": 29,
  "per_employee_price": 4,
  "trial_start": "datetime",
  "trial_end": "datetime",
  "trial_used": true,
  "subscription_status": "trial_active",
  "billing_active": false,
  "payment_method_on_file": false,
  "employee_count_billable": 0,
  "next_invoice_date": null,
  "canceled_at": null
}
Billing calculation

Monthly price formula:

monthly total = 29 + (billable employee count × 4)

Example:

5 employees = $49/month
10 employees = $69/month
25 employees = $129/month

Tell Replit to count only active employees marked billable.

Replit implementation instructions for billing logic
Implement the Paylink billing model with these rules:

Plan:
- Starter Plan
- $29/month base
- $4 per active billable employee per month

Trial:
- 30-day free trial
- one trial per company
- during trial, subscription_status = trial_active
- when trial expires:
  - if payment method exists and billing is approved, convert to active_paid
  - if payment method does not exist, set subscription_status = trial_expired and restrict key features

Billing formula:
monthly_total = 29 + (active billable employees * 4)

Store:
- billable employee count
- next invoice date
- last invoice amount
- subscription status
Part 4 — Soft Lockout / Upgrade Wall
Goal

After the free trial ends, the user should still be able to log in and see their data, but important actions should be blocked until they subscribe.

This creates pressure to convert without making users feel trapped or instantly locked out.

Block these actions after trial expiration

If subscription_status = trial_expired, block:

running payroll
exporting reports
adding new employees
editing employee records
clock in/out processing if you want tighter enforcement
advanced reporting
admin settings changes

Allow:

login
dashboard access
read-only employee list
subscription/billing page
support/contact page
Upgrade modal copy
Headline

Your free trial has ended

Body

Your company setup and employee data are still available. To continue using payroll, time tracking, and employee tools, activate your subscription.

CTA

Activate Subscription

Secondary CTA
Contact Support

Replit implementation instructions for soft lockout
Create a post-trial upgrade wall for trial-expired Paylink accounts.

Requirements:
- If subscription_status = trial_expired:
  - allow user login
  - allow dashboard view access
  - allow read-only access to core company and employee data
  - block payroll runs
  - block exports
  - block adding employees
  - block editing employee records
- Show a modal or banner:
  “Your free trial has ended. Activate your subscription to continue using Paylink.”
- Add a strong CTA button to activate billing.
- Keep this behavior server-enforced, not just frontend-enforced.
