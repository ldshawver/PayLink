1. Quick QA Test Prompt for Replit
Use this first to quickly validate the PayLink system before deeper testing.
Prompt
You are acting as a software QA engineer auditing the PayLink payroll platform.
Perform a quick automated validation of the entire application to identify any immediate failures.
Your tasks:
Scan the entire codebase and verify:
no unresolved imports
no missing dependencies
no broken routes
no syntax errors
no missing templates or components
Crawl the application and test all routes:
homepage
login
dashboard
employee management
timesheets
payroll runs
reports
HR modules
settings
tax wizard
Flag any routes returning:
404
500
runtime exceptions
Validate database connectivity.
Confirm tables exist and load:
employees
timesheets
payroll_runs
pay_codes
pay_stub_accounts
policy_groups
accrual_accounts
tax_tables
reports
Perform a simulated workflow:
Create test employee
Clock in and clock out
Generate timesheet
Run payroll
Generate pay stub
Generate payroll report
Confirm all processes execute successfully.
Validate key payroll calculations:
regular pay
overtime
tax deductions
net pay
Test report generation:
Ensure reports load and export correctly:
payroll summary
employee hours
overtime report
tax liability report
Validate check printing preview and pay stub formatting.
Output a quick QA report including:
broken features
failed routes
missing database relationships
payroll calculation errors
Prioritize blocking errors that would prevent payroll from running.
2. Full Restart + Deployment Validation Prompt (VPS)
Use this after fixes are applied to ensure the system deploys cleanly to your VPS.
Prompt
You are performing a production deployment verification for the PayLink payroll system.
Your objective is to confirm the system deploys cleanly and runs correctly on the VPS server.
Perform the following steps.
Step 1 — Stop Existing Services
Stop all running instances of the application.
Check for running processes such as:
gunicorn
node servers
background workers
cron jobs
Terminate them safely.
Step 2 — Pull Latest Code
Update the codebase from the repository.
Ensure:
latest commits pulled
dependencies updated
environment variables loaded correctly
Step 3 — Rebuild Environment
Reinstall all dependencies.
Verify:
Python packages
Node packages
database drivers
report generation libraries
PDF generation tools
payroll libraries
Confirm no dependency errors.
Step 4 — Database Validation
Run migrations and verify database integrity.
Confirm tables exist for:
employees
payroll
timesheets
tax tables
reports
HR records
accrual accounts
Ensure migrations complete successfully.
Step 5 — Restart Application
Start the application services:
backend server
background job workers
reporting engine
timeclock service
Verify the server starts with no errors.
Step 6 — Endpoint Health Check
Test all critical endpoints.
Verify response status:
login
dashboard
employees
timesheets
payroll
reports
tax wizard
HR modules
Ensure no 500 errors occur.
Step 7 — Payroll Functional Test
Simulate a payroll cycle:
Create test employee
Add timesheet entries
Run payroll calculation
Generate pay stub
Generate payroll report
Generate tax summary
Confirm calculations complete successfully.
Step 8 — Timeclock Validation
Test clock-in workflow:
Clock in
Clock out
Break start
Break end
Confirm entries appear in timesheets and feed into payroll.
Step 9 — Report Generation Test
Generate:
payroll register
employee hours
overtime report
accrual balances
Confirm export works:
CSV
Excel
PDF
Step 10 — Tax Form Validation
Test generation of:
W-2
1099
941
940
California DE-9
California DE-9C
Ensure forms populate correctly with payroll data.
Step 11 — Print Testing
Verify formatting and generation for:
pay stubs
payroll checks
Confirm printable output.
Step 12 — Final Deployment Report
Produce a report confirming:
system started successfully
payroll calculations executed correctly
reports generated correctly
no runtime errors
no broken endpoints
If issues are found, list:
severity
location
recommended fix
Recommended Final Instruction to Replit
At the end of both prompts, include:
"Do not stop at analysis. Actively run tests, simulate workflows, and verify outputs."
