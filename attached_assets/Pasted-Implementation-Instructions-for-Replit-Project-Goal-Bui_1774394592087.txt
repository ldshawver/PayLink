Implementation Instructions for Replit
Project Goal

Build a full-screen, animated hero section for the external website that features a classic time-punch style clock interface. The hero should serve two purposes:

Create a visually memorable landing experience.
Allow employees to use the clock interface to clock in or out.

As the user scrolls down, the large hero clock should smoothly scale down and transition upward, allowing the rest of the site content to appear below it.

Functional Requirements
1. Full-Screen Hero Section

Create a hero section that fills the full viewport height on page load.

It should contain:

a large animated classic-style punch clock
a digital live time display
a “Clock In” button
a “Clock Out” button
a small line of text below the clock:
Scroll down to see more

The hero should feel bold, polished, and slightly nostalgic, like a vintage employee time clock mixed with a modern SaaS landing page.

2. Clock Design / Visual Style

The clock should look like a classic wall-mounted or tabletop time punch machine, not just a plain digital widget.

Design cues:

rounded metal housing
brushed steel / matte black / deep charcoal finish
glowing screen or backlit time window
subtle shadows and highlights
old-school punch card slot or card tray detail
animated ticking second hand or soft mechanical motion
subtle idle movement to make it feel alive

Optional enhancements:

a slight “tick” or “flip” animation each minute or second
glowing accent around punch buttons
fake punch-card insertion effect when user clicks clock in/out
3. Live Time Behavior

The clock must display the current local time in real time.

Suggested display:

current time in HH:MM:SS
current date below or above the time
optional analog hands plus digital display

Use JavaScript to update every second.

4. Employee Clock In / Clock Out Interaction

The clock hero should allow employee use directly from the landing area.

Minimum functionality:

click “Clock In” sends a clock-in event
click “Clock Out” sends a clock-out event
show a short success state after action, such as:
“You are clocked in”
“Clock-out recorded”
disable duplicate clicks briefly while submitting
show loading animation while request is in progress

Recommended API contract:

POST /api/time/clock-in
POST /api/time/clock-out

Payload example:

{
  "employeeId": "current-session-user-id",
  "timestamp": "2026-03-24T18:23:00Z",
  "source": "landing-clock"
}

If employees are already authenticated, use session-based identity.
If not authenticated, the hero should route them to sign in before allowing punch actions.

Fallback behavior:

if not logged in, clicking either button opens login modal or redirects to /login
Scroll Animation Behavior
5. Shrink-on-Scroll Effect

As the visitor scrolls down:

the hero clock should smoothly scale down
move upward toward the top-center or top-left
the “Scroll down to see more” text should fade out
page content below should begin to appear naturally

This effect should feel smooth, premium, and modern.

Recommended behavior:

at top of page: clock is large and centered
after scrolling ~20–40% of viewport height: clock begins shrinking
after ~80–100% of hero scroll range: clock becomes much smaller and locks into a header-like position or fades into the next layout

Recommended CSS/JS tools:

use position: sticky for the hero inner container
animate scale and translate with transform
use requestAnimationFrame or scroll event throttling
avoid janky layout changes by animating transforms only

Behavior Details Replit Should Implement
7. Hero Layout Logic

The hero section should use a tall scroll region, not just a single 100vh snap section.

Recommended layout:

outer section height: 180vh to 220vh
inner clock container: position: sticky; top: 0; height: 100vh;
clock stays visible while user scrolls through the intro animation range
content below begins after the sticky region

This creates the “clock zooms smaller as user scrolls down” effect very naturally.

The front-end clock UI should connect to the existing employee/auth system.

Replit should:

if not authenticated, redirect to login or open a modal

Recommended backend endpoints:

POST /api/time/clock-in
POST /api/time/clock-out

Replit should use:

Example React Starter Code
PunchClockHero.jsx
import { useEffect, useState, useRef } from "react";
import { motion, useScroll, useTransform } from "framer-motion";

function PunchClock({ time, onClockIn, onClockOut, loading, status }) {
  return (
    <div className="clock-shell">
      <div className="clock-top">EMPLOYEE TIME CLOCK</div>
      <div className="clock-display">
        <div className="clock-time">{time}</div>
        <div className="clock-date">
          {new Date().toLocaleDateString()}
        </div>
      </div>

      <div className="clock-buttons">
        <button onClick={onClockIn} disabled={loading}>Clock In</button>
        <button onClick={onClockOut} disabled={loading}>Clock Out</button>
      </div>

      {status && <div className="clock-status">{status}</div>}
    </div>
  );
}

export default function PunchClockHero() {
  const [time, setTime] = useState(new Date().toLocaleTimeString());
  const [loading, setLoading] = useState(false);
  const [status, setStatus] = useState("");
  const sectionRef = useRef(null);

  const { scrollYProgress } = useScroll({
    target: sectionRef,
    offset: ["start start", "end start"]
  });

  const scale = useTransform(scrollYProgress, [0, 0.7], [1, 0.42]);
  const y = useTransform(scrollYProgress, [0, 0.7], [0, -220]);
  const hintOpacity = useTransform(scrollYProgress, [0, 0.2], [1, 0]);

  useEffect(() => {
    const interval = setInterval(() => {
      setTime(new Date().toLocaleTimeString());
    }, 1000);
    return () => clearInterval(interval);
  }, []);

  const requireAuth = () => {
    const isAuthenticated = true; // replace with real auth check
    if (!isAuthenticated) {
      window.location.href = "/login";
      return false;
    }
    return true;
  };

  const handleClockAction = async (type) => {
    if (!requireAuth()) return;

    try {
      setLoading(true);
      setStatus("");

      const endpoint =
        type === "in" ? "/api/time/clock-in" : "/api/time/clock-out";

      const res = await fetch(endpoint, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          timestamp: new Date().toISOString(),
          source: "landing-clock"
        })
      });

      if (!res.ok) throw new Error("Request failed");

      setStatus(type === "in" ? "Clock-in recorded" : "Clock-out recorded");
    } catch (err) {
      setStatus("Unable to record punch. Please try again.");
    } finally {
      setLoading(false);
    }
  };

  return (
    <section ref={sectionRef} className="hero-scroll-section">
      <div className="hero-sticky">
        <motion.div
          className="hero-clock-wrap"
          style={{ scale, y }}
        >
          <PunchClock
            time={time}
            loading={loading}
            status={status}
            onClockIn={() => handleClockAction("in")}
            onClockOut={() => handleClockAction("out")}
          />
        </motion.div>

        <motion.div className="scroll-hint" style={{ opacity: hintOpacity }}>
          Scroll down to see more
        </motion.div>
      </div>
    </section>
  );
}
