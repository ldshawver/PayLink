Expenses
I need a full audit and rebuild of the expense and contractor invoice area in PayLink.

Current issue:
Expenses were previously added as employee/contractor expenses tied to attendance. That is not correct. Expenses and invoices need to be separated from attendance and rebuilt as dedicated workflows.

Primary goals:
1. Allow employees and eligible contractors to submit reimbursable expenses.
2. Allow employees/contractors to enter company, project, job, and cost center expenses for reporting, taxes, and accounting.
3. Allow recurring expenses to be created and tracked.
4. Allow invoiced contractors to upload invoices for approval/payment.
5. Support upload or mobile camera capture for receipts/invoices.
6. Use AI to extract receipt/invoice data and auto-fill forms.
7. Route reimbursements and invoices through manager approval workflows.
8. Add approved reimbursable expenses to payroll correctly as reimbursement items.
9. Keep contractor invoices separate from payroll wages and route them to payable/export workflows.
10. Make the whole system exportable to outside accounting systems.

Required policy text:
Expense submission UI must display:
“All expenses must be approved by a supervisor or manager before they are incurred, or they will not be reimbursed.”

Invoiced contractor UI must display:
“A proposal must be approved before the invoice will be accepted. No work should be performed by an independent contractor unless proposal has been approved.”

Approval/payment rule:
Any expense needing reimbursement or any invoice needing payment must be approved by a manager or higher based on group permissions before reimbursement or payment can occur.

First task: audit the current system
Please audit and document:
- all current tables/models related to expenses, attendance, invoices, uploads, AI parsing, payroll reimbursements, accounting exports, jobs/projects/cost centers, and approvals
- whether expense logic is currently mixed with attendance
- whether invoices and expenses are currently separate
- whether current worker groups can support permissions and workflows
- whether current upload/camera/AI extraction features already exist
- whether payroll currently supports reimbursement items
- whether accounting export support already exists
- missing validation rules
- missing reports
- backward compatibility concerns

Then implement the upgraded architecture below.

A. Separate modules
Create separate modules for:
- Expense Management
- Contractor Invoice Management
- Recurring Expenses
- AI Receipt/Invoice Extraction
- Approval Workflows
- Payroll Reimbursement Bridge
- Accounting Export

B. Expense submission
Allow employees and eligible contractors to:
- create expense submissions
- upload receipt/invoice files
- take photos on mobile devices
- edit AI-extracted fields before submission
- assign company, legal entity, project, job, and cost center
- request reimbursement if applicable
- track status

Required expense fields:
- submitter
- legal entity / company
- expense date
- category
- amount
- receipt/supporting document
- merchant/vendor name
- business purpose
- reimbursement requested yes/no
- project/job/cost center if applicable
- payment method used
- preapproval status or reference if required

Validation rules:
- positive amount required
- receipt required based on category/rule thresholds
- preapproval required for selected categories
- duplicate detection for receipts/submissions
- project/cost center required when configured
- manager approval required before reimbursement

C. Contractor invoice submission
Allow invoiced independent contractors to:
- upload invoice files
- take photos on mobile
- use AI extraction
- edit extracted values
- submit invoice for approval
- link invoice to approved proposal
- track status

Required invoice fields:
- contractor assignment
- legal entity / company
- invoice number
- invoice date
- amount
- invoice file/photo
- proposal reference / approved proposal ID
- description of work
- project/job/cost center if applicable
- payment terms

Validation rules:
- no invoice accepted without approved proposal unless manager override permission
- duplicate invoice detection
- positive amount required
- contractor must be active/approved
- invoice must not be treated as payroll wages

G. Approval workflow
Build approval workflows for both expenses and contractor invoices.
Roles should include at minimum:
- submitter
- supervisor
- manager
- payroll admin
- AP/admin
- company admin

Expense flow:
submitted -> supervisor review -> manager approval -> payroll reimbursement queue or AP queue -> reimbursed/paid -> exported -> closed

Invoice flow:
submitted -> proposal validation -> manager approval -> AP/payment queue -> paid -> exported -> closed

All approval actions must be logged immutably.

H. Payroll reimbursement bridge

Requirements:
- reimbursement item must remain separate from wages
- support taxable/non-taxable flag
- link back to source expense
- include in payroll net pay only when approved
- report YTD reimbursements separately from compensation

I. Contractor invoice handling
