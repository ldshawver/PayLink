Security

Enterprise-Grade Security at Every Layer

PayLink handles SSNs, bank routing numbers, wage data, and medical information. We take that responsibility seriously at every level of the stack.

Zero-Trust API Authentication

Every API endpoint independently enforces authentication and role checks server-side. The frontend never controls data access — a logged-out user cannot reach any data endpoint regardless of URL manipulation.

Multi-Tenant Data Isolation

Every database record is scoped to a company ID enforced server-side on every query. A cross-company data leak is architecturally impossible — not just a UI safeguard.

Banking Data Protection

Direct deposit routing and account numbers are only accessible to authenticated users through employee-scoped endpoints. ACH files are generated and handled server-side with no exposure to client storage.

Document Audit Trails & Legal Hold

Every document view, download, edit, and signature is logged with user identity and timestamp. Legal hold prevents deletion regardless of user role — required for litigation protection and compliance audits.

Session & Password Security

Sessions stored server-side in PostgreSQL, never in client cookies. Cookies are httpOnly, Secure, and SameSite-protected. Passwords hashed with bcrypt (cost factor 10). Automatic session expiry enforced.

Field-Level Access Whitelist

Employees updating their own records can only modify whitelisted fields (contact info, address, emergency contacts). Pay rates, roles, and wage history cannot be self-modified — even with a direct API call.
